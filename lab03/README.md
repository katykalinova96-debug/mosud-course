## Исходное отношение и атрибуты

Исходное отношение `olist.order_reviews`. Для варианта используются поля `order_id`, `review_score`, `review_comment_message`. Условие выборки: `review_score <= 2 AND review_comment_message IS NOT NULL`. После проекции столбцы называются `order_id`, `score`, `comment_message`.

## Реляционная алгебра

Обозначим исходное отношение через `R = order_reviews`.

`ρ_{score ← review_score, comment_message ← review_comment_message}(π_{order_id, review_score, review_comment_message}(σ_{review_score ≤ 2 ∧ review_comment_message IS NOT NULL}(R)))`

Последовательные выборки:

`σ_{review_comment_message IS NOT NULL}(σ_{review_score ≤ 2}(R))`

Ранняя проекция:

`σ_{review_score ≤ 2 ∧ review_comment_message IS NOT NULL}(π_{order_id, review_score, review_comment_message}(R))`

Ранняя проекция сохраняет все поля, необходимые для последующего фильтра и результата.

## Вывод

Выборка `σ` соответствует фильтрации строк через `WHERE`, проекция `π` — выбору столбцов через `SELECT`, переименование `ρ` — применению псевдонимов `AS`. Сложный предикат можно разделить на две последовательные выборки без изменения результата. Исключение ненужных столбцов на раннем этапе сохраняет результат, если остаются все поля для фильтрации и вывода. В математической реляционной алгебре проекция формирует множество уникальных кортежей; SQL `SELECT` без `DISTINCT` может сохранять повторения. Эквивалентность запросов проверяется через `EXCEPT ALL`, учитывающий кратность строк.

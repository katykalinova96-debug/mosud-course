## Ответы на контрольные вопросы

**1. Почему `NULL = NULL` не даёт `TRUE`?**  
`NULL` обозначает неизвестное значение, поэтому результат сравнения — `UNKNOWN`. Для проверки отсутствия значения используется `IS NULL`.

**2. Как предикат в `WHERE` влияет на строки после внешнего соединения?**  
При `LEFT JOIN` строки без совпадения получают `NULL` в столбцах правой таблицы. Условие на эти столбцы в `WHERE` может исключить такие строки, в отличие от условия в `ON`.

**3. Почему `NOT EXISTS` устойчивее `NOT IN` при наличии NULL?**  
`NOT IN` может вернуть `UNKNOWN`, если в наборе есть `NULL`. `NOT EXISTS` проверяет отсутствие подходящих строк и не зависит от постороннего `NULL` в подзапросе.
